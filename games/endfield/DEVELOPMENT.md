# 终末地适配与开发

## 帧如何处理

游戏先完成 DLSS 超分。默认配置在游戏的 Vulkan 设备上以一层 NR 处理超分后的图像。模型工作尺寸默认宽高各为输出的 50%。1440p 输出时，工作尺寸约为 1280 × 720，输出仍为 2560 × 1440。这种配置把 NR 的工作像素降为原尺寸的四分之一，同时省去额外 D3D12 处理链路。实际收益取决于模型、画面、显存与 GPU 负载。

用户可在 Home 中选择工作分辨率。画面页的「保留原色与暗部」复用已有外观合成，适合排查整体偏色、偏暗。高级设置使用整数滑条，拖动时预览，松手才提交。帧生成页复用 MFG Unlock 的已有状态和运行库上限。默认一层超分后 NR，可以单独验证真实渲染节奏。 [上游 Vulkan 架构](https://github.com/Yukikaze20170315/endfield-dlss5-vulkan-plugin/releases/tag/unified-20261103l)

## 安装范围

安装器优先查找鹰角启动器记录和常用游戏目录，验证找到的是 Windows 版终末地。部署时使用官方 ReShade Vulkan 层，保留游戏自带 Streamline 和现有画质。新安装采用渲染前 0、超分后 1、呈现 0，已有 NR 配置保留。

候选 Generic 与 MFG 必须来自同一次构建。下载的外部文件按固定版本和 SHA-256 校验。RTX 50 的 NR 运行库还检查 NVIDIA 签名。安装失败时回退该次托管的变更。系统共享的 ReShade Vulkan 层可能已用于其他程序，卸载时仅处理本安装器的文件和应用登记。

## 构建与验证

GitHub Actions 的 Windows 环境负责生成两份原生 add-on，再构建自带这两份组件的安装器。构建依赖放在工作目录，仓库保留源码和许可证。

测试分为两层。安装器先在临时目录验证路径识别、完整性检查和失败回退。实机先验证 Vulkan 启动和 Home 面板，再固定场景对照 NR 关闭、开启后的真实帧率、长帧和显存占用。呈现次数和输入延迟分别统计。 [离线回归与实机验收](plugin/tools/endfield-validation/README.md)

## 新游戏

在 `games/<游戏标识>/` 下增加该游戏的源码、安装入口和验证文档。终末地的目录识别、运行库和默认层数由本游戏独立管理。
